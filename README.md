# День рождения ♡ — бесплатная отправка в Google Таблицу

Никаких платных сервисов. GitHub Pages остаётся хостингом сайта.

## 1. Настроить Google Apps Script (один раз)

1. Открой https://script.google.com/ под тем Google-аккаунтом, у которого есть **права редактирования** таблицы.
2. Создай **Новый проект**.
3. Удали содержимое `Code.gs` и вставь код из одноимённого файла в этом архиве. Сохрани.
4. Нажми **Deploy / Развернуть → New deployment / Новое развёртывание**.
5. Тип: **Web app / Веб-приложение**. **Execute as: Me / От моего имени**.
   **Who has access: Anyone / Все**. Это нужно, чтобы девушка могла отправить ответы без входа в Google.
6. Нажми **Deploy**, разреши скрипту доступ к таблице и отправке писем.
7. Скопируй URL веб-приложения, который заканчивается на `/exec`.

## 2. Подключить сайт

1. Открой `config.js` и замени `PASTE_GOOGLE_APPS_SCRIPT_EXEC_URL_HERE` на скопированный URL `/exec`.
2. Загрузи обновлённые `app.js` и `config.js` в корень GitHub-репозитория.
3. Файл `Code.gs` загружать в GitHub **не нужно** — он должен быть только в Google Apps Script.
4. Открой GitHub Pages, пройди тест и проверь вкладку `Ответы` в таблице.
5. Если почта не пришла, проверь папку «Спам» и журнал **Executions / Выполнения** в Apps Script.

**Важно:** из-за ограничений браузера и Google Apps Script сайт может подтвердить
только передачу запроса, а не факт записи в таблицу. Обязательно проверь тестовую
строку в таблице перед отправкой ссылки девушке.

Google Apps Script имеет бесплатные квоты. Google-аккаунт, скрипт и таблица
должны быть под твоим контролем. Ссылка веб-приложения доступна посетителям,
поэтому не используй этот приёмник для конфиденциальных данных.
