# Твой день ♡ — интерактивный опрос

Готовый статический сайт. Не нужен Vercel, Node.js, сборка или сервер.

## Настройка за 5 минут

1. Открой `config.js` и замени `YOUR_EMAIL@example.com` на **свой** email. Сохрани.
2. На GitHub создай **публичный** репозиторий, например `birthday-story`. Загрузить нужно **содержимое** папки `birthday-story` (файлы `index.html`, `style.css`, `app.js`, `config.js` и папку `photos`), а не ZIP как один файл.
3. GitHub → Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, folder **/(root)** → Save.
4. Через несколько минут адрес будет `https://ТВОЙ-ЛОГИН.github.io/birthday-story/`.
5. **Обязательно протестируй**: открой сайт, пройди анкету до конца. На твой email придёт письмо подтверждения от FormSubmit. Подтверди адрес по ссылке в письме. После активации сделай **вторую** тестовую отправку и проверь, что ответы пришли. Проверь папку «Спам».
6. После успешного теста отправь девушке ссылку.

## Как работает отправка

На последнем экране сайт автоматически делает POST-запрос к FormSubmit. Девушке не нужно открывать почту или нажимать «Отправить». Если нет интернета или сервис недоступен, сайт покажет кнопку повторной отправки; ответы останутся в браузере. Отправка **не гарантируется** при блокировке стороннего сервиса, поэтому перед запуском проверь работу на телефоне.

**Важно:** FormSubmit — сторонний сервис, ответы обрабатываются им и пересылаются на твой email. Не собирай через форму конфиденциальные данные. Email организатора указан в публичном `config.js` и доступен посетителям сайта. Для скрытого email/защиты от спама потребуется серверный обработчик. Данные опроса также сохраняются локально в браузере девушки до очистки хранилища. Фотографии в публичном репозитории и на GitHub Pages доступны любому, у кого есть ссылка, а репозиторий — всем. Убедись, что все изображённые согласны на публикацию.

## Настройка дизайна и вопросов

- Вопросы и ветвление — массив `Q` в `app.js`. Условия `when` показывают вопросы только для подходящего сценария.
- Фотографии — `photos/p01.webp` ... `photos/p24.webp`. Они сжаты для быстрой загрузки.
- Цвета — переменные `:root` в `style.css`.
- Итог отображается девушке и отправляется тебе целиком.

## Особенности

- 22 вопроса (часть появляется по условиям), мультивыбор, свободный текст, количество гостей, бюджет, кухня, программа, время и запреты.
- Автосохранение черновика в localStorage.
- Мобильная адаптация и интерактивная галерея из 24 фотографий.
- Не собирает контактные данные девушки.
